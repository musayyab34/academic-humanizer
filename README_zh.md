# Academic Humanizer 学术写作去AI味工具

**English: [README.md](README.md)** · **版本记录：[CHANGELOG.md](CHANGELOG.md)**

这是一份规则手册，任何 AI 读了都能照着做：去掉学术写作里的"AI味"，同时不改动任何研究内容。

支持中文和英文，适用于：

- 小论文（期刊、会议论文）
- 大论文（学位论文）
- 开题报告、中期报告
- 实验报告、每周汇报

它会处理"值得注意的是""具有重要意义""赋能""随着……的快速发展"、英文里的 "Moreover""crucial" 以及只会重复前文的总结句。它还会找出**回避性写作**：像"取得了一定进展""效果较好"这种没有具体内容的句子。它不会替你编内容，而是列出每句话还缺什么，让你自己补。

它**不会**重写你的文档。所有数字、引用、公式、术语和结论都保持原样。

## 文件说明

| 文件 | 用途 |
|---|---|
| `SKILL.md` | 规则手册。AI 只需要这一个文件。 |
| `scripts/humanizer_check.py` | 可选的检查脚本，确认修改前后数字、引用和公式没有变化。 |
| `tests/test_checker.py` | 检查脚本的测试。只有修改脚本时才需要。 |

## 使用方法

### 方法一：任意对话式 AI（DeepSeek、Kimi、豆包、ChatGPT、Claude 等）

1. 上传 `SKILL.md` 和你的文档。
2. 发送这句话：

   > 按照 `SKILL.md` 的规则去除附件文档的 AI 味，严格遵守其中的规则，并按要求给出报告。

3. 你会拿到两个文件：修改后的文档和一份单独的报告。

### 方法二：编程类 AI 工具（Codex、Claude Code、Cursor 等）

`SKILL.md` 符合通用的 Agent Skills 格式，这些工具可以直接作为 skill 加载。

1. 把这个文件夹放进工具的 skills 目录，并命名为 `academic-humanizer`，例如：
   - Claude Code：`~/.claude/skills/academic-humanizer/`
   - Codex：`~/.codex/skills/academic-humanizer/`
2. 在工具里打开文档所在的文件夹，然后说："帮我去掉这篇文档的 AI 味。"
3. AI 会按规则修改，并自动运行检查脚本。

## 保留原文不改的部分

如果有些句子一个字都不能改：

- 在提示词里写明："以下内容不要改动：……"，或者
- 在文件里标记：
  - LaTeX：在前一行写 `% keep`，后一行写 `% /keep`
  - Markdown：用 `<!-- keep -->` … `<!-- /keep -->` 包起来
  - Word：写在提示词里，或者写进一个文本文件，配合检查脚本的 `--protect` 选项使用

## 你会拿到什么

1. **修改后的文档**，格式和原文件一样（Word 还是 Word，LaTeX 还是 LaTeX）。
2. **一份报告**（`…_humanizer_report.md`），按重要程度排列：
   - 可能改变原意的修改（请优先检查）
   - **待补充内容**：空泛的句子，以及每句需要回答的具体问题
   - 只有作者本人能处理的问题（缺少引用、可疑的参考文献、前后不一致的数字）
   - 检查了哪些内容，以及字数变化
   - 修改前后的各类问题数量

每周汇报和中期报告会把"待补充内容"放在最前面。

## 检查脚本（可选）

需要 Python 3，不用安装其他东西。支持 `.tex`、`.md`、`.txt` 和 `.docx` 文件，中英文都可以。Word 文件会读取正文、公式、脚注和尾注，不读取页眉、页脚、批注和文本框。

```
python scripts/humanizer_check.py 周报.docx                    # 统计 AI 味特征
python scripts/humanizer_check.py 原稿/ 修改稿/                 # 对比两个版本
```

结果说明：

- **0，一致**：脚本列出的文件中，识别到的数字、引用和公式，数量和顺序都没变。
- **1，有改动**：有内容被增加、删除或修改，修好之前不要使用。
- **2，需复查**：内容都在，但顺序变了，请确认没有数字或引用挪到了别的结论下面。
- **3，未检查完整**：已检查的部分没有变化，但有内容没能检查（例如缺少 `\input` 的文件）。补上后重新运行。

脚本只负责计数和对比，判断不了某个数字是否还对应原来的结论，所以一定要看报告开头列出的修改。脚本列出的空泛句子和疑似提示词残留只是提醒你去看，不一定是错误。

## 注意事项

- 最适合计算机、工程等理工科写作。文科或医学写作，可以在提示词里加一句："与 Part 2 冲突时，按照［你的学科］的写作规范处理。"
- 不做翻译。中文保持中文，英文保持英文。
- 它不是用来对付知网、维普、万方等 AIGC 检测的，也不保证任何检测结果。目标是写出人读起来自然的文字。各校的 AIGC 要求不同，请以本校最新通知为准。
- 这是辅助修改的工具，不是用来隐瞒 AI 使用的。学校或期刊要求声明 AI 使用情况的，仍然需要声明。
